# Coffee Shop Management (Vue 3 + Vite)

Run:
    npm install
    npm run dev

CRUD: menu items and orders (stored in localStorage).
Topics: form handling (MenuForm, NewOrder), limiting events (useDebounce in MenuList),
parent-child communication (MenuCard props/emits), route configuration (src/router),
Options API vs Composition API (OrderDetails is Options API), mixins (formatMixin) and
composables (useLocalStorage, useDebounce, useStore), local storage (useLocalStorage).
